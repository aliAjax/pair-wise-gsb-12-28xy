# 车辆调度小工具

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

可落盘的派单闭环前端，数据保存在浏览器 localStorage（键：`dfwlfront-3-dispatch`），刷新后任务、车辆占用与修订链自动恢复。

## 业务规则

- **派单**：每单记录配送时段（开始/结束）、货重、配送区域、车辆与司机。
- **冲突拦截**：
  - 同一车辆或同一司机，时段重叠即冲突；跨日班次按 `[开始, 结束]` 连续区间占用。
  - 货重超过车辆载重即冲突。
  - 冲突时页面列出明细：冲突车辆/司机、冲突任务、重叠时段、超重差额，提交按钮保持可点，不靠禁用按钮提示。
- **状态闭环**：待执行 → 执行中 → 已完成（待执行可取消）。待执行与执行中占用资源，完成后释放。
- **执行中锁定**：执行中的任务不能更换车辆或司机（表单禁用 + store 层强制），其余字段可改并重新校验冲突。
- **修订留痕**：已完成任务不可修改、不可删除，只能「新建修订」生成带来源的新单；修订号沿链单调递增，旧记录保留，卡片上可双向查看来源与后续修订。

## 代码结构

- `src/stores/dispatch.ts`：Pinia store，状态、持久化、派单/编辑/修订/状态流转动作
- `src/lib/conflicts.ts`：冲突检测（车辆/司机时段重叠、超重差额）
- `src/lib/time.ts`：时段重叠、跨日判断、时间格式化
- `src/components/`：派单表单（含冲突明细面板）、任务列表、车辆占用看板、车辆与司机管理
