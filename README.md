# 车辆调度派单闭环

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 派单闭环规则

- 每单记录：配送时段（日期 + 起止时间）、货重、配送区域、车辆与司机。
- 同一车辆或同一司机，时段重叠的派单会被拦截；货重超过车辆载重也会被拦截。
- 结束时间不晚于开始时间视为跨日班次，自动顺延到次日，按连续时段占用。
- 执行中的任务不能更换车辆或司机（界面锁定 + store 强制）。
- 已完成订单不可编辑、不可删除，只能「新建修订」：生成带来源（sourceId）的新派单，旧记录保留，修订链可追踪。
- 冲突时页面列出明细：冲突车辆、冲突司机、重叠时段（含重叠时长）与超重差额，而不是只禁用按钮。

## 数据与持久化

- 领域逻辑在 `src/domain.ts`（纯函数：时段解析、重叠判定、冲突检测、修订链分组）。
- 状态与持久化在 `src/store.ts`（Pinia）：车辆、司机、派单、单号计数器整体写入
  `localStorage`（key：`dfwlfront-3-dispatch`，带版本号，旧结构自动重置为种子数据）。
- 车辆/司机「占用」由进行中派单（待执行 + 执行中）的时段推导，刷新后任务、占用与修订链保持一致。
